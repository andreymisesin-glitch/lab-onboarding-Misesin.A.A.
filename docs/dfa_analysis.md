# Анализ потоков данных

Цепочки Def-Use:
- log_entry: def 2, def 9. use 10.
- status: def 5. use 9, 11.
- balance: def 6. use 7.
- new_balance: def 7. use 8.
- file: def 10. use 11.

## Найденные дефекты

1. Status не создается, если amount <= 0. 
Строка 5 находится внутри if. Если amount меньше нуля или равен ему, мы идем дальше и на строке 9 пытаемся прибавить status к строке. Программа упадет с UnboundLocalError. И return status на строке 11 тоже не сработает.

2. log_entry на строке 2 бесполезен. 
Сначала пишем "Start processing", а на 9 строке сразу перезаписываем результат. Первое значение никто не читает.

3. Файл не закрывается. 
На 10 строке открываем через open(), пишем и все, close() нигде нет. Надо было написать with open("audit_log.txt", "w") as file:, тогда он сам закроется. У нас на парах говорили, что без этого файл может остаться занятым, даже если ошибка вылетит.
