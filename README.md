# Аудит компьютера (Практика 8, часть 2)

Скрипт `pc_info.bat` собирает данные о ПК и проверяет, подходит ли он для офисной работы.

## Какие программы я считаю базовыми и почему
Для работы офисному сотруднику нужен минимальный набор:
1. **Офисный пакет** (Word, Excel и т.д.) — чтобы работать с документами.
2. **Браузер** — для доступа в интернет и корпоративные системы.
3. **Читалка PDF** — для просмотра договоров и счетов.
4. **Архиватор** — чтобы открывать архивы из почты.
5. **Антивирус** — для базовой защиты.

*Нюанс:* Скрипт ищет браузер Edge, но в отчете помечает, что это системная программа, а не заслуга админа.

## Какие программы я считаю лишними
Скрипт ищет программы, которых обычно не должно быть на рабочем месте, и делит их на группы:
*   **Игры:** Steam, Epic Games и т.д.
*   **Торренты:** uTorrent, qBittorrent и т.д. (нагружают сеть).
*   **Мессенджеры:** Telegram, Discord и т.д. (могут быть запрещены, но иногда используются для работы).
*   **Развлечения:** OBS, Wallpaper Engine.

*Важно:* Скрипт не удаляет программы, а только пишет: «Рекомендуется проверить». Окончательное решение принимает человек.

## Как я проверял, что логика работает
Чтобы убедиться, что скрипт реально анализирует, а не просто печатает текст:
1. Я временно удалил из кода поиск архиватора. Скрипт сразу выдал рекомендацию его установить. Потом я вернул код обратно.
2. Я добавил в список программ тестовую строку "Steam". Скрипт сразу определил её в раздел "Игровое ПО". После проверки строку убрал.

## Ограничения скрипта
*   Он не умеет смотреть, когда программа запускалась в последний раз (в Windows это сложно сделать через консоль).
*   Он ищет по ключевым словам в названиях. Если программа называется странно, скрипт может её не узнать.
*   Все рекомендации — это повод для проверки, а не приказ к удалению.
