# Деобфускация

Расшифрованная строка: import os; os.system('rm -rf /')

Угроза тут максимальная. Скрипт использует base64 чтобы спрятать команду, а потом выполняет её через exec. В итоге срабатывает системная команда rm -rf /, которая полностью удаляет всю файловую систему. Если запустить это от рута, компьютер просто умрет.

Как защищаться:
1. Не использовать exec и eval для данных, которые пришли извне.
2. Поставить линтер безопасности (вроде Bandit), он сразу подсветит такие опасные команды.
3. Не запускать скрипты с правами администратора без острой необходимости.
