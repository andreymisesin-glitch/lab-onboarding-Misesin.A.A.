# Отчет по практике 7

## 1. Анализ потоков данных
Таблица Def-Use и подробное описание лежат в файле docs/dfa_analysis.md.

Если кратко, нашел три бага:
1. Переменная status не создается, если amount <= 0. Из-за этого будет ошибка UnboundLocalError на строке 9.
2. Мертвое присваивание у log_entry. Строку 2 мы перезаписываем на строке 9, так и не прочитав.
3. Утечка ресурса. Файл открывается через open(), но не закрывается. Надо юзать конструкцию with open().

## 2. Дизассемблирование
Подробности в docs/disassembly_analysis.md.
Код считает сумму чисел от 1 до 10. 
Вот эквивалент на Python:
total = 0
i = 1
while i <= 10:
    total += i
    i += 1

## 3. Деобфускация
Подробности в docs/deobfuscation.md.
Строка внутри base64 расшифровывается как: import os; os.system('rm -rf /')
Это команда полного удаления системы. Опасно тем, что exec просто берет и выполняет этот код.
Защита: не использовать exec для внешних данных, юзать анализаторы безопасности и не давать скриптам лишних прав.
