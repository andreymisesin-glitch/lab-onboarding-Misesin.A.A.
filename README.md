Аудит компьютера (Практика 8, часть 2)

Скрипт pc_info.bat собирает данные о ПК и проверяет, подходит ли он для офисной работы.

Какие программы я считаю базовыми и почему:
Для работы офисному сотруднику нужен минимальный набор: офисный пакет (Word, Excel) для документов, браузер для доступа в интернет, читалка PDF для договоров, архиватор для открытия архивов из почты, и антивирус для защиты.
Отдельно отмечу нюанс: скрипт ищет браузер Edge, но в отчете помечает, что это системная программа, а не заслуга админа.

Какие программы я считаю лишними:
Скрипт ищет программы, которых обычно не должно быть на рабочем месте, и делит их на группы: игры (Steam, Epic Games), торренты (uTorrent, нагружают сеть), мессенджеры (Telegram, Discord, могут быть запрещены, но иногда нужны для работы) и развлечения (OBS, Wallpaper Engine).
Важно: скрипт не удаляет программы, а только пишет «Рекомендуется проверить». Окончательное решение принимает человек.

Как я проверял, что логика работает:
Чтобы убедиться, что скрипт реально анализирует данные, а не просто печатает заготовленный текст, я проверил обе ветки логики.
Во-первых, я временно удалил из кода поиск архиватора. Скрипт сразу выдал рекомендацию его установить, после чего я вернул код обратно.
Во-вторых, я добавил в список программ тестовую строку "Steam". Скрипт сразу определил её в раздел "Игровое ПО". После проверки строку убрал.

Ограничения скрипта:
Он не умеет смотреть, когда программа запускалась в последний раз (в Windows это сложно сделать через консоль). Поиск идет по ключевым словам в названиях, поэтому странно названную программу скрипт может не узнать. И главное: все рекомендации — это повод для проверки, а не приказ к удалению.
